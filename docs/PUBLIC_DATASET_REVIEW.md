# 公开数据集核查与燕渡评测接入建议

核查日期：2026-11-15。对照代码：`codex/model-evaluation`，提交 `1bbf607f`。

后续已接入商品文案和 Products-10K，并各完成 8 例真实接口试跑，见[接入说明](PUBLIC_DATASET_INTEGRATION.md)与[抽样测评报告](PUBLIC_DATASET_PILOT_REPORT.md)。下文保留接入前的资源核查结论。

这些数据可以补充商品文本、商品照片和检索样本。优先考虑 **Products-10K 的商品图片**和**商品描述文案的标题—描述对**；MUGE 适合单独评测图文检索；JDSUM 需要申请。当前最缺的是校园交易字段的人工标准答案，以及真实拍照场景。

本轮检查了发布说明、原始来源、文件目录、许可标记、下载入口和部分样本。MUGE 的作者预处理包已通过 HTTP Range 实际读取目录及前三条验证样本；其余数据没有进行完整下载与全量质量统计。本轮没有运行候选模型。

## 六个链接的结论

| 同学提供的资源 | 实际内容与标注 | 对燕渡的用途 | 接入判断 |
| --- | --- | --- | --- |

## 已核查的内容、获取方式和限制

### Unsplash：可取样，但缺少我们的任务答案

[官方仓库](https://github.com/unsplash/datasets)提供约 25,000 张照片的 Lite 版本；[字段文档](https://github.com/unsplash/datasets/blob/master/DOCS.md)显示，`photos.tsv` 包含图片 URL、摄影者描述及 `ai_description`，关键词表区分人工建议与 AI 信号。照片需要按链接获取，元数据压缩包不是全部原图。

本次对 Lite 下载地址发出 HEAD 请求，返回 200、ZIP、320,024,071 字节。官网与仓库展示的版本规模不完全一致，正式实验应记录实际下载版本与文件哈希。

适合补充通用物品和非商品图片。摄影网站的画面构图不能代表宿舍杂乱背景、模糊书名、多件物品合照；AI 描述也可能有误，须人工判断图片能支持哪些事实。[数据集条款](https://github.com/unsplash/datasets/blob/master/TERMS.md)限制数据再分发，不能把取样原图直接随评测代码公开提交到 GitHub。

### TAOBAO-MM：不是自然语言解析数据集

官方说明中的样本量约 9,900 万，提供 Parquet 表和 128 维量化向量，整体分发目录约 139 GB。其输入是匿名 ID、行为序列及特征，目标是点击或未点击；原始图片等多模态内容不发布。[项目说明](https://taobao-mm.github.io/)、[Hugging Face 数据预览](https://huggingface.co/datasets/TaoBao-MM/Taobao-MM)都能核实这一结构。

这些向量不能作为视觉大模型的原图输入，也没有可供需求解析的买家原话及预算、校区等标签。即使点击预测表现好，也不能据此判断燕渡的解析或商品匹配质量。本轮无需下载。

### 商品图像目录：优先考察 Products-10K

目录中的 Products-10K 覆盖 3C、服饰、家居等商品，同时含商家图片和消费者图片，与燕渡日常物品比纯食品货架数据更接近。原始标签是 SKU 类别，并不是燕渡的六个业务分类。[原始论文](https://arxiv.org/html/2008.10545v1)介绍约 15 万张图片、约 1 万个 SKU，经人工复核，并说明用于非商业研究和教育。

[Kaggle 数据页](https://www.kaggle.com/competitions/products-10k/data)已打开，列出 `train.csv`、`test.csv`、`sampleSubmission.csv`；字段为 `name`、`class`、`group`，图片包另由 OneDrive / JD Pan 提供。Kaggle 数据访问要求登录并接受赛事规则。本轮没有取得图片包和类别映射文件，不能报告实际图片可用率。

目录写“近 19 万张”，原论文和 Kaggle 页面写“近 15 万张”；正式接入应以取得版本的文件清单统计。目录的 GPL-3.0 也不能替代各数据集自身条款。

对我们的视觉接口，应抽取相关商品后补标：业务类别、可见名称与属性、不可从图像判断的字段、主体是否清楚。没有产品名称或参考图映射时，不能要求通用大模型直接输出无语义的 SKU 数字 ID。

### AI Studio 177548 / MUGE：图文检索用途最明确

百度页显示 `Multimodal_Retrieval.zip`，大小 1250.90M，列出 `MR_train/valid/test_imgs.tsv` 和相应 query JSONL。页面标记 CC BY，并提示数据集尚未迁移至平台新版本。其描述、文件名与[原始天池赛题](https://tianchi.aliyun.com/competition/entrance/532031/information)一致；尚未做两个压缩包的哈希比对。

原始任务将图片缩放到 224×224 并保存为 base64；训练和验证 query 包含相关图片 ID，测试 query 不公开答案。训练集约 25 万 query—商品对，验证和测试各约 5,000 个 query，在各自约 3 万张候选图片中检索。原始字段是 `query_id/query_text/item_ids`。[赛题说明](https://tianchi.aliyun.com/competition/entrance/532031/information)

[Chinese-CLIP 作者仓库](https://github.com/OFA-Sys/Chinese-CLIP)另提供预处理后的 [MUGE.zip](https://huggingface.co/datasets/OFA-Sys/chinese-clip-eval/blob/main/MUGE.zip)。本次 HEAD 返回 200，大小 2,633,309,970 字节；读取 ZIP 目录及前三条验证样本共传输了 6,880 字节。样本采用 `text_id/text/image_ids`，其中第一条搜索词是“圣诞 抱枕”，对应 6 个图片 ID，与[作者示例 Notebook](https://github.com/OFA-Sys/Chinese-CLIP/blob/master/Chinese-CLIP-on-MUGE-Retrieval.ipynb)一致。包内含 train、valid、test 的图片 TSV 和文本 JSONL；没有全量解码图片。

**评分口径须区分：**作者[评分脚本](https://github.com/OFA-Sys/Chinese-CLIP/blob/master/cn_clip/eval/evaluation.py)的 Recall@K 是“前 K 个结果至少命中一个标注相关图”的 query 比例。这不等于燕渡的 P@5，也不等于检出全部相关图的比例。不能用它替换现有候选精筛的 MATCH / NO_MATCH / UNCERTAIN。

这份数据缺价格、校区、成色及完整商品事实；224×224 图片也不适合承担精细书名 OCR 的主要验收。若用于独立图文检索，可先使用有答案的验证集；若抽样改造，需保留候选池、原始 ID，并单独命名结果口径。未标为相关的图片不能自动当作经人工确认的负例。

许可方面，百度镜像的 CC BY 与赛事页面通用协议中的用途限制并不一致。作者公开的预处理包能够访问，不代表数据获得新的宽松许可；接入课程评测、外部模型 API 或公开样本前，需核实原始数据的适用授权。这里记录的是已看到的页面差异，未代为报名或申请。

### JDSUM：有详细文字，获取存在审批流程

已从聚合页追到[国家基础学科公共科学数据中心原始条目](https://www.nbsdc.cn/general/dataDetail?id=64edc979bb16e07753c35b96&type=1)。发布机构为北京京东尚科信息技术有限公司，版本 v1.0，资源标识 `CSTR:16666.11.nbsdc.jTwXeIVv`。条目介绍约 45 万组“详细介绍—图片—摘要”，覆盖家电、服饰、箱包；摘要由人工撰写。

页面明确显示“审批后共享”。元数据列出 8 个文件、86.67GB，摘要又写约 97GB；未取得数据说明文件和样本，暂不能确认实际 JSON 字段、划分或缺失比例。公开页面也没有提供足够明确的再分发许可。

它能提供商品事实与长文本素材，但摘要可能概括图片不可见的功能。评测视觉接口时，只能以可见证据为答案；评测文本提取时，才能依据输入文字。不能把完整商品摘要直接当成“只看图”的标准答案。检索到的 CEPSUM 相关项目也不应在版本未核实前与此 45 万条 JDSUM 混用。

### AI Studio 36884：适合文本素材，第二个包不是商品属性标签

百度页列出 `item_desc.zip`（233.07M）和 `content_tag.zip`（295.69M），`item_desc.zip` 内为 `item_desc_dataset.txt`。点击下载实际弹出百度登录界面。页面同样提示尚未迁移，未验证登录后能否下载。

其原始来源是[天池商品描述文案数据集 9717](https://tianchi.aliyun.com/dataset/9717)，页面给出两类 TSV：

| 文件 | 原始页面记录数 | 两列含义 |
| --- | ---: | --- |
| `item_desc_dataset.txt` | 2,129,187 | 商品标题、商品描述文案 |
| `content_tag_dataset.txt` | 1,094,689 | 文本内容、点击该内容的用户类型分布 |

第二个文件的“tag”不是燕渡所需的商品分类、成色或语义标签，不能直接导入 `expected.sets.tags`。第一份适合抽样补标商品分类与事实；宣传语不提供校园交易地点、卖家实际转让价或二手成色。

原作者 [THUDM/KOBE](https://github.com/THUDM/KOBE)称其为 TaoDescribe，提供标题、文案、条件及检索知识的处理版本和[下载脚本](https://github.com/THUDM/KOBE/blob/master/kobe/data/download.py)。本次脚本中的清华网盘入口 HEAD 返回 403；Google Drive 入口未完成下载验证。因此只能确认存在作者下载途径，不能称其已在本机成功获取。

**许可标记有冲突：**百度镜像写 CC0；天池页顶部写 CC-BY-SA-NC 4.0，正文写 CC BY-NC 4.0。原始页面两处都包含非商业限制，但是否要求相同方式共享还需确认。课程数据说明应记录这一差异，不应把它写成无条件 CC0 数据。

## 与现有测试框架如何衔接

当前 `evals/schema.py` 仅接受 `intent_parse`、`item_parse`、`wanted_parse`、`candidate_review`。视觉业务已存在于 `backend/app/vision.py`，但视觉评测适配器和评分规则尚未实现。

| 评测任务 | 可以利用的外部素材 | 仍要补的标准答案或实现 |
| --- | --- | --- |
| 商品文本提取 | TaoDescribe / JDSUM 的描述文本 | 六类业务分类、明确出现的价格与成色、校区、标签；缺失字段及澄清判定 |
| 买家需求与求购解析 | MUGE 的短搜索词可补品类表达 | 真实买家原话；预算、必须条件、排除条件、偏好、校区、冲突与澄清标签 |
| 候选匹配精筛 | 商品文本可组成候选库 | 独立需求、真实或明确构造的候选字段、三分类结论及证据；区分不满足与无法判断 |
| 图片生成发布草稿 | Products-10K；MUGE；少量 Unsplash | 新视觉任务、图片加载及缓存处理；类别、可见事实、主体状态、多图去重和合照拆分标签 |
| 图文检索 | MUGE 原生相关图片标注 | 新检索适配器、固定候选池、R@K 评分；与现有文本精筛报告分开 |

商品文案可先转换成现有 `item_parse` JSON 用例，人工标注后即可走当前 CLI。图片和检索不能仅往 JSON 增加字段就直接运行，需要扩展 schema、适配器及评分器。视觉评测必须使用真实业务提示词，并避免服务缓存让重复测试只返回同一次结果。

数据管理时保留来源 URL、版本、原始 ID、许可核查状态、转换方法和人工复核人。同一商品、多视角照片和改写文本归到同一 `family`，整组划分 dev/holdout，防止同源样本进入两边。原文改写或补充虚构交易字段后，应标作“基于公开素材构造”，不能报告为真实校园交易数据。

候选模型使用同一组人工复核样本、业务提示词和固定评分规则，分别报告每任务质量、失败率、延迟与可核算费用。公开数据诊断与校园保留集分别展示；最终按校园任务门槛筛选，再在质量达标的模型间比较成本和延迟。不能凭公开榜单或下载成功选出模型。

## 建议准备的材料

下一轮可以沿用现有 48 条合成开发用例调试，再建立独立保留集。下面是首轮工作量建议，不是已经取得的数据量或统计充分性结论。

| 材料 | 建议规模 | 必须覆盖的内容 |
| --- | ---: | --- |
| 真实校园文本及人工答案 | 需求 50 条、出售 30 条、求购 20 条 | 中文金额、原价与转让价、预算修正、否定、偏好、校区别称、字段缺失、条件冲突 |
| 需求—候选商品组及人工答案 | 20 组，每组 3–5 件 | 满足、不满足、信息不足；相近商品、缺少关键属性、价格或校区冲突 |
| 手机拍摄测试输入及人工答案 | 50 组，每组 1–3 张 | 书籍、数码、家电、服饰、运动用品；模糊/遮挡、合照、同物多角度、非商品输入 |

明早优先向同学收集上述真实文本和照片，保留素材提供者同意用于课程测试的记录并移除联系人等个人信息；同时补齐愿意采用数据集的原始下载包/README/许可，尤其是 MUGE 与商品文案的来源条款差异。JDSUM 可申请后再补，不作为首轮评测的前置条件。

运行真实选型还需要候选模型的精确 ID、服务地址和可用调用额度，密钥通过执行环境配置。当前选型策略仍是 draft，正式跑保留集前应固定评分规则和通过门槛；先用少量开发样本核算调用量，再执行正式比较。
